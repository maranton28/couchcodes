# CouchCodes

An offline-first, controller-friendly companion app for **GTA VI** D-pad cheat codes, unlock challenge tracking, and hands-free Couch Mode voice readout.

## Features
- **Offline-First Catalog + OTA JSON Sync:** Instant local boot with non-blocking remote JSON manifest updates as new community codes are verified.
- **Challenge Unlock Tracker:** Track progress across all 61 in-game unlock prerequisites and filter to usable codes only.
- **Couch Mode:** High-contrast oversized D-pad directional arrows with `expo-speech` voice readout and haptic step feedback.
- **Pinned Chaos Bar:** Quick-access horizontal bar for your most-used codes.
